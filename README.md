# CtOS — учебный симулятор в стиле Watch Dogs

Настольное приложение на Python/Tkinter в эстетике ctOS из Watch Dogs, сделанное
для курса по информационной безопасности МИВЛГУ. Все «атаки» в модулях —
визуализации и интерактивные симуляции: реального взаимодействия с сетью,
Wi-Fi или чужими устройствами приложение не производит.

## Модули

- **BRUTEFORCE** — симуляция подбора пароля к Wi-Fi: сканирование сетей,
  фазы рукопожатия (ASSOC / EAPOL / MIC / PMK), «словарный» перебор,
  скачивание файлов после «успеха».
- **DATA EXFIL** — симуляция утечки данных с сервера на удалённый узел:
  переключатели шифрования/сжатия/TOR, лог событий, статистика сессии.
- **NETWORK SNIFFER** — симуляция перехвата трафика: инвентарь устройств,
  граф узлов сети, переключатель MITM, лог пакетов.
- **ZERO-DAY** — мини-игра: провести питание через сетку узлов от START
  через GATE до EXIT, вращая элементы кликом.
- **SOCIAL ENG. / PHISHING** — заглушки, модули в разработке.

У каждого сценарного модуля есть кнопка **INFO** с пошаговым туром по
интерфейсу и финальной теоретической справкой: что это за атака, как от неё
защищаться и почему симуляция не заменяет реальный взлом.

## Требования

- Python 3.11+
- pygame (звук и музыка)

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Управление: `F11` — переключить полноэкранный режим, `Esc` — выйти из
полноэкранного режима, `Enter` — продолжить с заставки.

## Тесты

```bash
pip install pytest
pytest
```

## Сборка .exe (Windows)

```bash
pip install pyinstaller
pyinstaller main.spec
```

Готовый exe появится в `dist/`. Иконка (`icon.ico`), звуки (`sound/`) и
`music.mp3` подключены в `main.spec` как ресурсы приложения.

## Структура проекта

```
ctos/
  bruteforce_config.py   # данные и тексты модуля BRUTEFORCE (сети, профили, INFO-тур)
  config.py              # пути к ресурсам и таймауты приложения
  contracts.py           # общий протокол ExploitModule для сценарных модулей
  modules/                # сценарные модули: bruteforce, data_exfil, network_sniffer,
                          # zero_day, placeholder_module + registry.py (реестр модулей)
  services/               # SoundService — звуковые эффекты и фоновая музыка
  ui/                     # главный экран (application.py), палитра (theme.py),
                          # масштабирование под разрешение (viewport.py)
  utils/                  # мелкие общие хелперы (форматирование, безопасные after-job'ы)
tests/                    # pytest-тесты (bruteforce_config, formatting)
main.py                  # точка входа
main.spec                # конфигурация PyInstaller
```

Добавление нового сценарного модуля не требует правок в UI меню: модуль
регистрируется в `ctos/modules/registry.py` и добавляется узлом в
`graph_nodes` в `ctos/ui/application.py`.
